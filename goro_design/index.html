CHARACTER SELECT

キャラクター選択

〜既存のキャラクターを使いたい方へ〜
ゴローデザインに参加するクリエイターのキャラクターから、お好みの一体をお選びいただけます。まずは種類と動き方をお選びください。ご依頼はゴローデザインが窓口となって進めます。

キャラクターの動き方は 2種類 から選べます。同じキャラでも、両方に対応できる場合があります。

PATTERN 1

平面的に動く

デザインの中で動きます。名刺やカードの枠の中で、絵がそのまま動き出すイメージです。背景ごと動かせるので、風景や世界観を見せたいときに向いています。

PATTERN 2

立体的に飛び出す

デザインの枠から飛び出して動きます。キャラクターだけが切り抜かれ、その場に立っているように見えます。渡した相手が思わず二度見するインパクトが出ます。

動き方：

この条件のキャラクターは準備中です。ほかの動き方もお試しください。

お探しのキャラが見つからない場合 ご相談ください →
